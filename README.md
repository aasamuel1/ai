# 🎬 AI Video Series Production Framework

**An open, end-to-end framework for producing episodic AI-generated story videos** — from script and character design to publishing on YouTube Shorts, TikTok, and Reels.

This repository packages a complete, battle-tested production workflow: series planning, character consistency prompts, scene-by-scene AI video generation prompts, voiceover direction, editing checklists, and a publishing schedule. It ships with a fully worked example — a 3-episode emotional series, *"The Security Guard"* — so you can study a real production package, not just theory.

## ✨ Why this exists

AI video tools (Kling, Hailuo, Runway, Pika, Veo) can generate stunning clips, but creators struggle with the two hardest problems:

1. **Character consistency** across scenes and episodes
2. **A repeatable production pipeline** that turns a story into publishable episodes

This framework solves both, using **reference-image locking** and a **structured prompt system** you can reuse for any story.

## 🚀 Quick Start (5 steps)

1. **Read** `01-series-plan.md` to understand the 3-episode structure.
2. **Lock your characters** — generate reference images using `02-character-bible.md`.
3. **Generate clips** — copy each scene prompt from the episode scripts into Kling AI / Hailuo / Runway (image-to-video works best).
4. **Add voiceover** — paste the narration into ElevenLabs with a deep, aged male voice.
5. **Edit & post** — assemble in CapCut with captions and music, then follow the publishing schedule in `06-production-guide.md`.

## 🎯 The Worked Example: *"The Security Guard"*

A 3-episode emotional series set in Lagos, Nigeria:

- **Ep 1 — "My Daughter Owned the Bank"** — the fall, the promise, the shocking job offer *(cliffhanger: he accepts)*
- **Ep 2 — "Three Years Invisible"** — the humiliation, the evening ritual, the villain arrives *(cliffhanger: shouting on the executive floor)*
- **Ep 3 — "That Security Guard Is My Father"** — the rejection, the revelation, the hug, the lesson

## 💡 Golden Rules

- Same character reference image in every generation = consistency
- Hook in the first 5 seconds, cliffhanger at the end of Eps 1–2
- Always add subtitles — most viewers watch muted
- End the final episode with a question CTA to drive comments
